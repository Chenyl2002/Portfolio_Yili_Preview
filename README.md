# 陈宜理 · 中文作品集独立预览

基于 Bruno Simon 作品改编的可驾驶中文作品集。保留可见作者署名、MIT、中文字体 OFL 及第三方许可证。此仓库仅发布独立 GitHub Pages 预览；原 Portfolio_Yili 仓库与 chenyili.fun 域名不变。

## 当前版本

- 修正破冰推进流程文案与实际展板、资料身份与现行联系信息、独立后备视频控制、当前与历史经历来源、在线留言不可用提示、重复经历文案、作者与测试范围说明，以及影像终端状态。
- 资料页码输入支持 Enter 和可见跳转按钮；覆盖边界、重复操作、关闭和切换文档。键盘教学以 E 为主要提示并说明 Enter/F 与场景焦点。
- 全图到访成就采用实际可见的 13 个目的地。旧满进度只保留有证据的 11 个有效身份，需重新访问两个经历入口，不能自动补造访问或阅读记录。
- 地图传送增加目的地、状态、取消及失败恢复；不宣称首次传送的长停顿已消失，主线程阻塞仍可能延迟提示与计时。
- 三条经历世界标签增加窄屏适配，仅调整可见文字，不移动交互目标或地图节点。阅读期间抑制移动风线，退出后按当前输入状态恢复。
- 阅读页的显示身份等待绘制和 GPU 完成信号，涵盖取消、超时、失败和过期任务；这尚不等于真实 GPU/合成器验收。
- 破碎之家只对中性材质带做局部可逆调色，保留其他项目、机制色、全局光照与地面；同光照实机对比仍待完成。
- 保留七个联系雕像与原台座对应关系、原始简历及作品集合辑、原地图底图与几何、其他项目、车辆物理及玩法。

## 检查范围与限制

本轮十组现行回归及生产构建通过，覆盖实机反馈修复、原节点保护、项目内容、沉浸展板、地图/经历、草地、影像终端、联系雕像、轮胎间隙和身份字体。部分测试使用源码、画布、DOM 或 GPU 信号替身，不能据此宣称真实设备体验通过。发布另验证确定性增量、分卷与文件哈希、独立还原、许可证及安全回归。

四个历史可选脚本仍失败，并已在未修改的上一版基线上复现：旧展板点击夹具、两个旧交互中心接口夹具，以及更早版本 Player 哈希夹具。这些失败未计入通过结果。现有静态 URL 解析与大 chunk 构建提示仍存在。

本轮没有重新渲染地图。当前场景几何独立导出两次，完整字节与已发布地图几何一致；保留原底图与渲染证据，并增加当前来源连续性核验。离线地图着色不展示新增的破碎之家局部材质调整。

修复版仍需真实设备复测：四项目快速翻页及中断恢复、GPU 显示同步、传送真实耗时和取消恢复、13 个目的地进度、390 px 经历标签、页码 Enter/触控、阅读风线、破碎之家同光照材质，以及微信/B站/电话入口。B站页面响应不能代替实际视频播放成功。不得将此预览理解为全部实际 QA 已通过。

## 离线还原

九个 preview.zip.partNN 与 manifest.json 保留原始基底 93b16facda9ed4abc903ba749b4e88e4f8ab7afd。preview-delta.zip.partNN 为每卷不超过 8 MiB 的确定性增量；release-manifest.json 记录分卷、精确删除集合和全部最终文件的 SHA-256。

在没有 dist 的干净仓库副本运行：

```sh
python3 extract_preview.py
```

提取器无需安装依赖或联网，验证路径、类型、分卷、增删集合、许可证及最终文件后生成 dist，并拒绝覆盖已有 dist。保留的 GitHub Actions 工作流发布经过验证的静态网站。

公开包仅含网站构建资源、用户批准公开的作品与联系资料、许可证和还原工具，不含开发源码、私有配置、凭据或自定义域名设置。
