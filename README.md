## 离线还原

九个 preview.zip.partNN 与 manifest.json 保留原始基底 93b16facda9ed4abc903ba749b4e88e4f8ab7afd。preview-delta.zip.partNN 为每卷不超过 8 MiB 的确定性增量；release-manifest.json 记录分卷、精确删除集合和全部最终文件的 SHA-256。

在没有 dist 的干净仓库副本运行：

```sh
python3 extract_preview.py
```

提取器无需安装依赖或联网，验证路径、类型、分卷、增删集合、许可证及最终文件后生成 dist，并拒绝覆盖已有 dist。保留的 GitHub Actions 工作流发布经过验证的静态网站。

公开包仅含网站构建资源、用户批准公开的作品与联系资料、许可证和还原工具，不含开发源码、私有配置、凭据或自定义域名设置。
