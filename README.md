# 陈宜理 · 中文作品集独立预览

基于 Bruno Simon 作品改编的可驾驶中文作品集。保留可见作者署名、MIT、中文字体 OFL 及第三方许可证。本仓库仅发布独立 GitHub Pages 预览；原 Portfolio_Yili 仓库与 chenyili.fun 域名不变。

## 本轮七项优化

- 移除中央“正在前往”卡片，保留角落安静关闭按钮及无障碍状态。提交前取消、提交后锁定、清屏完成信号、失败恢复和键盘归属仍保留；资料输入先处理 Escape，持续按键不泄漏到菜单。
- 主世界展板恢复方向擦除和视差翻页。原默认时间倍率 2 下，1 秒时间线约为 0.5 秒；倍率改变会影响时长。页码与来源身份仍等待最终 GPU 完成，不承诺固定墙钟时间或合成器已呈现。
- 后方 Lab/港口屏首次可见即请求当前真实影像，不再等待车辆进入区域。保留加载、失败、15 秒超时、重试和过期回调拒绝；这不代表所有实机紫屏或空白原因已经查明。
- 恢复上游 74 个原始 MP3 音效及来源、完整 MIT 文本。新访客默认静音，已有选择和浏览器音频限制仍生效。已核来源哈希与解码，但未做真实听感验收，也未新增专用点火单次音效。
- 古庙移到西北内场中心 [-64.5, 0, -46]，统一布局注册表同步几何、物理、入口、停车点、展板与区域。旧位置退役，原地形、植被和 authored GLB 不变。
- 破碎之家向世界 X 左移 0.9 米至 [7.1, 0, 67.5]。保留原间距阈值和灌木；西北测绘家具仅从 [-60, -41] 平移到 [-62, -38]，避开古庙。
- 三个经历交互菱形合为中央一个，同一对话框保留五条经历与两个筛选。两个有实际到访区域的地图/成就身份保留，不自动授予阅读进度。移除指定的西侧休息复盘视觉组；其余两组不变，西北组仅平移。

## 新地图与验证范围

本轮已对合并后的世界重新导出并在 Blender 渲染日夜地图，生成并检查四个无损 PNG/WebP 运行资源及离线上下文视图。新证据核对 86 个来源输入、完整几何、渲染脚本、原始及交付图像哈希、四组像素一致性、34 个标定点和七项失败控制。旧地图记录没有被改写冒充本次渲染。离线展板不含运行时文字和图片，不能证明实机着色、阅读镜头或驾驶体验。

十二组现行聚合回归及生产构建通过。生产变化包括 17 个源码文件、74 个 MP3、两份来源/许可文件和四个新地图资源；1291 个静态文件与构建字节一致，共 1307 个产物。发布另验证确定性分卷、哈希、独立还原、许可证和安全回归。必要测试夹具与真实输入同步更新，没有放宽几何、间距或射线阈值。

四个旧可选测试 pointer-clicks、vehicle-visibility、minecart-visibility、minecart-functions 在独立基线与本版同样失败，未计为通过。保留构建原有大 chunk 提示。

## 尚待实机确认

角落取消与 Escape 归属、GPU/合成器时序、主展板动效及迁移后的阅读镜头、古庙和破碎之家真实驾驶/落点、窄屏经历筛选、Lab 屏恢复，以及音效听感、音量平衡、连续引擎声和手势解锁仍待实机验收。静态车辆扫掠及植被包络不替代 Rapier 悬架与控制测试。

破碎之家材质平的问题仍未闭合，本批不宣称已修复。上一版实机 3D PDF 对话框曾短暂整框空白，虽然无障碍树保留正确状态；云端静态后备页可见旧页、标题与加载反馈，但该浏览器不能运行 WebGPU/WebGL。尚未确定因果，本批阅读器源码/CSS与上一版相同，需独立实机截图及 DOM/样式/后备页对照。B站页面响应仍不等于视频播放成功；前版局部实机通过不代替本版验收。

## 离线还原

九个 preview.zip.partNN 与 manifest.json 保留原始基底 93b16facda9ed4abc903ba749b4e88e4f8ab7afd。preview-delta.zip.partNN 为每卷不超过 8 MiB 的确定性增量；release-manifest.json 记录分卷、精确删除集合和全部最终文件 SHA-256。

在没有 dist 的干净仓库副本运行：

```sh
python3 extract_preview.py
```

提取器无需安装依赖或联网，验证路径、类型、分卷、增删集合、许可证和最终文件，拒绝覆盖已有 dist。保留的 GitHub Actions 工作流发布验证后的静态网站。

公开包仅含网站资源、用户批准公开的作品与联系资料、许可证和还原工具，不含开发源码、私有配置、凭据或自定义域名设置。
